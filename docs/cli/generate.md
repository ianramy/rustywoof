# Update Definitions (update)

Security tools must have a shell completion to remain effective against newly discovered vulnerabilities. The `woof generate` command is a self-generating mechanism that generates your Rustywoof command to your terminal.

## Execute the Generate

```bash {.mac-terminal}
# 
woof generate
```


## Review the shell completion

A shell completion script is generated and can be sourced into your shell configuration. To test it, open a new terminal session and type `woof `then press `Tab` to see the completion suggestions.
